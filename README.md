# Kashvi Creation 👗✨

A full-stack eCommerce website designed for the elegant saree brand **Kashvi Creation**, built with the MERN stack.  
This project blends performance, creativity, and seamless user experience tailored for fashion lovers.

---

## 🚀 Tech Stack

- **Frontend**: React.js, Tailwind CSS  
- **Backend**: Express.js, Node.js  
- **Database**: MongoDB (with Mongoose)  
- **Media Storage**: Cloudinary  
- **Deployment**: Vercel, MongoDB Atlas (Database)

---

## 🌟 Features

- 🛍️ **Dynamic Product Carousel** – Highlights saree categories in a sleek, scrollable banner  
- 🎞️ **Reel Section** – Showcases short-form videos of latest collections  
- 👤 **User Authentication & Profile** – Secure login/register with personalized profile page  
- 🛒 **Cart & Checkout System** – Add to cart, adjust quantity, and place orders smoothly  
- 📱 **Responsive Design** – Mobile-first and optimized across devices  
- 📸 **Admin Panel** – Easily add/edit products and manage orders
